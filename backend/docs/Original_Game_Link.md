## Original Connect 4 Implementation

We chose to recreate connect four using python for a more interesting
challenge than tic tac toe. 

The original code was written in vanilla 
html, js and css. There is a C++ implementation of the minimax algorithm
for the game but this was not used for our implementation.

We used vanilla html, css and js for the front end, and a python
backend for the game logic and handling of events and AI communication.

The original code can be found here:
[Github link](https://github.com/balkarjun/ConnectFourAI/)
